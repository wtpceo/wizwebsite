# 홈 메시지 설계: 대표가 말한 회사의 그림 (2026-11-06)

대표가 11/6 저녁에 말한 것을 홈 카피의 기준으로 옮긴 문서다. 개발자(김민우)의 `shortform-home` 가지 위에서 카피만 손본다. 디자인과 46컷 구조는 그대로 둔다.

되돌리는 법: 개발자가 넘긴 상태는 태그 `dev-handoff-2026-11-06`에 있다. `git checkout dev-handoff-2026-11-06 -- components/shortform app/\(ko\)/page.tsx public/sf/sf.js`로 되돌린다. 작업은 `ceo-edit` 가지에서 한다.

## 1. 대표가 말한 것 (원문 요지)

- 이 홈페이지는 파워링크와 메타 광고의 착지 페이지로 쓴다.
- IMC 회사로 운영한다. 주 매체는 인플루언서·유튜버 섭외 제공이다.
- 기업 문의가 들어오면 먼저 문제를 찾는다. 홈페이지 SEO·GEO 상태, 마케팅 후킹이 부족한 페이지, 브랜드 채널 정비 상태, 주요 플랫폼 노출 현황. 마케팅 퍼널의 현재 위치를 파악하고 부족한 부분을 제안한다. 기술이 하나로 정해져 있지 않다.
- 많은 마케팅 회사는 매체 하나만 다루고 나머지는 외주를 준다. 그러면 성과가 아니라 "이렇게 해 주기로 했고 다 했다"는 이행 내역을 가지고 싸운다.
- 우리는 성과가 날 때까지 처음부터 끝까지 함께한다.
- 촬영팀이 있어 필요하면 직접 찍는다. 퍼포먼스 부서, SEO·GEO 부서, 개발 부서, AE가 다 있다.
- 전화로만 하지 않는다. 성과 보고도 전문 AE가 직접 찾아뵙고 보고하고 팀을 움직인다.
- 영업하는 사람과 실행하는 사람이 따로 있지 않다. 모두가 하나의 전문성을 가지고 함께 움직인다.
- GEO는 realGEO 툴로, 인플루언서는 위플루언서 툴로 움직인다. 매체별 설명 랜딩에 참고한다.
- 디자인은 괜찮다. 카피와 고객에게 전체 그림을 그려 주는 힘이 약하다. 히어로는 나쁘지 않은데 설득력이 약하다.

## 2. 한 문장으로

> 문의가 오면 먼저 브랜드의 빈 곳을 찾고, 필요한 것만 인하우스 팀이 직접 실행해, 전담 AE가 찾아뵙고 성과로 보고하는 회사.

고객이 홈을 다 넘기고 나서 기억해야 할 것은 이 세 가지다.

1. 진단이 먼저다. 정해진 패키지를 파는 게 아니라 퍼널의 빈 자리를 찾아 제안한다.
2. 한 매체가 아니라 퍼널 전체를 한 팀이 본다. 외주로 넘기지 않으니 "다 했다"로 끝나지 않는다.
3. 보고 기준이 성과다. 전담 AE가 직접 찾아뵙는다.

## 4. 쓰지 않는 말

- 1위·최고·보장·No.1, 종합 광고대행사, 광고주 수 같은 규모 숫자(검수 전까지), 고객사 상호.
- 결과 약속으로 읽히는 말("매출이 오릅니다"). 성과를 **보고 기준**으로 말하되 성과를 **약속**하지 않는다.

## 5. 자료 위치

- realGEO 화면 6장: `wizwebsite/public/tools/realgeo-*.jpg` (대시보드·주간 리포트·모니터링·프롬프트·사이트 진단·알림). 홈 검색 컷에는 `/images/report/report-1.jpg`(realGEO 리포트 띠)가 이미 들어가 있다.
