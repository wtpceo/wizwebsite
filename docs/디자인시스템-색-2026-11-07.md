# 위즈더플래닝 색 체계 제안 「먹과 신호」 (2026-11-07)

대표 뜻: 성과주의, 터프하지만 일 잘하는 회사. 파랑 같은 평화적인 색보다 빨강이 섞인 색. 빨강이 메인은 아니지만 자주 보이는 체계. 때로는 밝고 때로는 어두운 회사.
시트: `public/mock/ds.html` (로컬 /mock/ds.html). 캡처: `docs/시안-퍼포먼스-2026-11-07/ds.jpg`.

## 한 줄

종이와 먹이 바닥, 빨강은 신호. 한 화면에 한 번, 눌러야 할 곳과 움직인 숫자에만 켜진다. 기본은 밝고, 증거를 보여 줄 때 어두워진다.

## 비율 (화면 전체 기준)

종이 60 · 먹 30 · 회색 7 · 빨강 3. 빨강이 3을 넘기면 신호가 아니라 배경이 된다. 파랑은 체계에서 뺀다. 지금 사이트의 코발트(#0D4F8C)는 바꿀 때 먹으로 대체한다.

## 빨강의 자리

켜는 곳: 화면마다 주행동 버튼 하나 · 움직인 숫자 옆 화살표나 글자 · 제목에서 한 어절 밑줄 · 표의 한 줄 띠 · 로고 끝의 점, 활성 메뉴.
끄는 곳: 배경 전체 · 본문 글자 · 한 화면에 두 군데 · 경고·오류 뜻(오류는 먹 바탕 흰 글자로) · 그라데이션과 반투명 빨강.

## 부품

- 버튼: 주행동은 빨강 단색, 보조는 먹 외곽선. 모서리 없음. 글자 800.
- 숫자: 먹 800, 움직임 표시만 빨강.
- 표: 바뀐 줄 하나만 red-100 띠, 글자 빨강.
- 표식: 제목 한 어절 아래 3px 빨강 선. 태그는 활성만 빨강 테두리.

## 글꼴

사이트 글꼴 Pretendard 그대로. 제목 800, 본문 400~600, 자간 -0.01em에서 -0.045em.

## 2차 (2026-11-07 밤) — 대표 사주 색 반영

대표 지시: 용신이 물·나무, 쇠가 그다음. 빨강·주황·분홍·자주(불)와 노랑·베이지·황토·갈색(흙)은 피한다. 빨강은 입력 오류 표시처럼 기능상 필요한 곳에만. 배경은 미색이 아니라 순백. 강조색은 위즈더플래닝 블루 #0055FF로 통일하고 위플 색은 섞지 않는다.

그래서 「먹과 신호」의 신호 빨강 #D9262C와 크림 종이 #F6F4EF는 뺐다. 자리와 규칙(화면당 한 번, 버튼·움직인 숫자·한 어절·한 줄)은 그대로이고 색만 바뀐다.

```css
/* 퍼포먼스 쪽(.pk)에 적용한 값 */
--paper: #FFFFFF;   /* 순백 바닥 (쇠) */
--paper2: #F2F4F7;  /* 칸 (쇠·회색) */
--ink: #14161A;     /* 글자 (물·검정) */
--ink2: #0A1A33;    /* 어두운 섹션·머리줄·바닥 (물·짙은 남색) */
--mut: #5B6573;     /* 보조 글자 (쇠·회색) */
--line: #DDE3EA;    /* 선 */
--sig: #0055FF;     /* 신호 = 위즈더플래닝 블루 (물) */
--sig-h: #0041C2;   /* 누름 */
--sig-l: #5B8CFF;   /* 남색 바닥 위 글자 표식 */
--sig-tint: #E8F0FF;/* 강조 띠 */
--wood: #0E8C7F;    /* 통과·운영 중 같은 긍정 상태 (나무·청록) */
--wood-l: #4FC3B4;  /* 남색 바닥 위 청록 */
```

빨강이 남은 곳: 하단 바와 문의 폼의 입력 오류 글자 #B01C24 한 군데뿐이다.
