## 4. 칸별 문안 설계

### 칸을 놓는 자리

서비스 쪽: 개요 → 상품 → 결과물 → 다른 점 → **진행과 보고(+기간표 · 받는 것 견본 · 사례 카드)** → 같이 하면 좋은 서비스 → **안 맞는 경우** → 자주 묻는 질문 **+ 이어 읽기** → **첫 상담** → 다른 서비스 → 문의

업종 쪽: 고민 → **업종별 첫 한 달(로컬만)** → 결과물 → 묶는 순서 → 진행(+사례 카드) → **안 맞는 경우** → 자주 묻는 질문 **+ 이어 읽기** → **첫 상담** → 문의

### 검색 최적화

**사례 카드: 네이버·제미나이엔 나오는데 ChatGPT만 모르던 정형외과** (2026.8.6 → 9.28)
- 처음 · 10개 중 4개: 환자가 물을 법한 질문 10개 가운데 ChatGPT 답에 이름이 나온 것은 4개였습니다. 야간·주말 진료 사실은 알면서 병원 이름과 잇지 못했습니다.
- 39일 뒤 · 17% → 93%: 같은 질문을 같은 방법으로 30번 다시 물은 언급률입니다. 병원 사이트가 출처로 달린 답은 0번에서 16번이 됐습니다.
- 2주 뒤 · 83%: 한 번 더 재니 10%p 내려갔습니다. 내려간 숫자도 그대로 적습니다.
- 아래 줄: 병원명·지역 비공개 · 고친 방법은 글 아래에서 사업자 인증 뒤 열람 · 같은 서비스의 다른 기록(ChatGPT 추천 1순위 2026.10.28 / 네이버 지도 201위 → 1위)과 「1위가 된 곳을 골라 적었다」 안내는 그대로 둠

**기간표: 언제쯤 달라지나요?**
- 시작할 때: 지금 상태를 잰 진단표와 고칠 곳 목록
- 2~4주: 틀린 정보 바로잡기
- 1~3개월: AI가 인용하는 곳이 넓어짐
- 매주: 같은 질문으로 다시 잰 표
- 근거 줄: 업종과 지금 상태에 따라 다르고 시점을 약속하지는 않습니다

**안 맞는 경우** (가이드 글 「GEO 대행이 맞지 않는 경우」를 줄여 옮김)
- 노출 보장을 원하실 때. 약속드릴 수 있는 건 같은 방법으로 다시 잰 숫자입니다.
- 한두 달 안에 매출로 확인하고 싶으실 때. 노출이 바뀌는 데만 보통 1~3개월을 봅니다. (원문 「빠른 곳도 2개월쯤」은 같은 쪽 사례 39일과 부딪혀 FAQ 표현으로 바꿈)
- 손님이 검색해서 찾아오지 않는 사업일 때. 소개로 영업이 대부분 돌아가면 AI 답에 이름이 나와도 달라지는 게 적습니다.
- 직접 할 시간이 있으실 때. 사이트를 손볼 줄 알고 매달 몇 시간을 낼 수 있으면 직접 하셔도 됩니다.
